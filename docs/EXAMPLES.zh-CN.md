# 示例对话

## 初次设置

```text
User：帮我设置一个不烦人的睡眠提醒。
Agent：可以。先问一个问题：你所在的时区是？
User：多伦多。
Agent：记为 America/Toronto。你希望通常几点起床？
…
Agent：是否明确同意把这些设置和之后的睡眠记录保存在本地？
User：不同意保存。
Agent：明白，我不会写入任何本地记录或提醒状态。我们仍可以只在当前对话里讨论作息。
```

## 晚安、继续聊天、再次晚安

```text
Agent：离你计划睡觉的时间还有一会儿，可以开始收尾、把节奏放慢了。
       [完成] [推迟] [跳过] [关闭此提醒]
User：完成。
Agent：好。准备睡觉时跟我说一声晚安就好。

Agent：准备睡觉时跟我说一声晚安就好，我会记录时间，然后保持安静。
User：晚安
Agent：晚安 🌙 已记下你在 23:06 准备入睡。我会保持安静，明早见。
User：还是睡不着。
Agent：我在。刚才的 23:06 仍只表示“准备入睡”，不会当成实际睡着时间。
User：我再试一次，晚安。
Agent：晚安 🌙 已更新为 23:42 准备入睡。我会保持安静，明早见。
```

## 早安快速记录

```text
User：早安
Agent：早安 ☀️ 已记录你在 07:32 报告醒来。昨晚大概多久睡着？
        [很快] [约半小时] [超过一小时] [不记得]
User：约半小时
Agent：昨晚起夜几次？
        [0] [1] [2] [3 次以上]
User：1
Agent：记好了。今天不会再追问。
```

## 补录与纠错

```text
User：早上七点就醒了，只是忘了说早安。
Agent：已把昨晚的报告醒来时间修正为今天 07:00；原值和这次修正会保留在本地审计记录中。

User：刚才不算晚安。
Agent：明白，刚才的准备入睡时间已取消；我不会把它当作睡着时间。

User：把昨晚的数据删掉。
Agent：已删除昨晚这一日的本地记录；该日记录及内部审计一并删除。
```

## 提醒控制

```text
Agent：离你计划睡觉的时间还有一会儿，可以开始收尾、把节奏放慢了。
       [完成] [推迟] [跳过] [关闭此提醒]
User：推迟二十分钟。
Agent：好，20 分钟后再提醒一次；现在不再打扰。

User：今天不提醒。
Agent：好的，今天余下的提醒都跳过。

User：以后少提醒。
Agent：可以。我先把睡前降速改为隔天一次，晚安邀请保持每天一次。这样合适吗？
```

## 健康安全边界

```text
User：我每晚都起夜三四次，而且很口渴，还打鼾。
Agent：这些情况持续影响睡眠，且同时有异常口渴和打鼾，值得请医生做专业评估。这个 Skill 不能判断原因。不要为了减少起夜而硬性禁水；口渴时仍可以小口喝水。
```
